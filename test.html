👁️ Focus Monitor - Test Page

Use this page to test the focus monitoring functionality before adding to Tampermonkey

⚠️ Important: Make sure you're running a local server for the models folder!
Run: python3 -m http.server 8000 in the project directory

How to Use This Test Page

  1. Make sure the local server is running (see warning above)
  2. Click the "Start" button that will appear in the top-right corner
  3. Grant webcam permission when prompted
  4. Keep your face in view - you should see "✅ Focused"
  5. Look away from the screen to test the away detection
  6. After 5 seconds, you should see a red warning screen

Sample Content for Testing

This is sample content that you would normally read or work with. The focus monitor will track whether you're looking at the screen.

Try looking away from the screen for more than 5 seconds to trigger the warning. The system uses face detection to determine if you're focused.

When the warning appears, click "I'm Back!" to dismiss it and reset the timer.

Tips for Best Results

  • Ensure good lighting on your face
  • Position yourself directly in front of the camera
  • Remove anything blocking your face (sunglasses, hat, etc.)
  • Stay within 1-3 feet of the camera

Next Steps

  1. If everything works here, copy the script from script.js
  2. Open Tampermonkey and create a new script
  3. Paste the script and save it
  4. The focus monitor will now work on all websites!
